# 实用工具（dsh-useful-tools）

组件化的 DSH 实用工具插件。插件管理界面提供独立的组件开关；设置中有单独的 **实用工具** 页面，每个组件有自己的子页。

当前包含 **会话命名** 组件。

版本：**0.1.2**。需要 Node.js `^22.19.0 || >=24.0.0`，支持 DSH `0.2.1-rc.2` 和 `0.2.2-alpha.2`。

## 会话命名

- 首轮结束就触发，使用首轮全部用户消息（含同轮补充）与这一轮已有的 AI 可见回复生成名称。只有用户消息、首轮报错或被中断时，也按当时已有内容发送；有多个模型步骤时，保留各步骤的可见回复，排除思考块、工具调用和注入的系统上下文。
- 原生图片附件随结构化内容一起提交；首条只有图片也能命名。命名模型必须支持视觉。
- 使用当前可见分支和编辑后的消息内容。命名属于只读辅助请求，不写聊天消息，不建立聊天生成检查点；请求期间分支或内容变化会使旧结果失效。
- 在原生会话重命名窗口的输入框右侧显示 **✦**。点击后基于当前可见分支的全部用户和 AI 消息重新命名，成功后直接保存并关闭窗口。
- 设置子页可独立选择服务商和模型；留空则优先使用该会话已记录的请求模型，没有请求记录时使用已选模型或该会话的实时模型。命名设置不会修改聊天所选模型。
- 手动输入名称或点击 ✦ 后的名称保持固定，不会被之后的自动命名覆盖。生成失败保留原有名称。

## 组件开关与恢复

在插件管理界面的 **实用工具** 包详情中，单独开启或关闭 **会话命名** 行。公共层保留配置和交接管理：组件开启时运行新命名逻辑，组件关闭时用原配置加载 DSH 自带的 `session-title-first-prompt-llm` 实现。默认提供方与自定义提供方的切换会先取消并排空旧请求。

插件包声明层暂时屏蔽原 `session-title-llm` 行，不改它的模型或生成参数。关闭或卸载整个插件包后，此层撤销，由 DSH 恢复原行。切换不会删除或重新生成已有标题。部署没有启用 HMR 时，DSH 可能要求重启才能应用插件管理改动。

公共层 `dsh-useful-tools` 行单独关闭时，也会撤销对官方行的屏蔽；重新开启后按组件行状态交接。独立功能开关使用 **会话命名** 行。更高优先级的配置若重新启用原命名插件，会报告接管冲突。

## 设置

打开设置 → **实用工具** → **会话命名**，选择服务商和模型后保存。两项都为空表示跟随当前会话；明确选择时两项必须配对。模型列表读取 DSH 的当前目录，不复制凭据或 API 地址。

默认限制：输入 65,536 字节，输出 1,024 tokens，超时 60 秒，标题最多 80 UTF-8 字节。输入预算包含所有文本、角色标记和图片引用元数据；图片字节预算沿用所选提供方的原生限制。超过预算会明确报错，保留旧标题，不静默截断会话。

## 安装

仓库已包含客户端运行文件，可直接在仓库目录生成安装包及校验文件：

```sh
npm pack --ignore-scripts
sha256sum dsh-useful-tools-0.1.2.tgz > dsh-useful-tools-0.1.2.tgz.sha256
```

将安装包及校验文件放到运行 DSH 的机器。若启用了 VCP 消息树，先安装配套的 `dsh-vcp-specific-ui 0.2.16` 并重启 DSH，再安装本包。没有使用 VCP 消息树时不必安装配套包。

在包文件所在目录执行校验，再用安装包的绝对路径安装；`web` 替换为实际 profile：

```sh
sha256sum -c dsh-useful-tools-0.1.2.tgz.sha256
dsh plugin --profile web add /实际路径/dsh-useful-tools-0.1.2.tgz
```

按 DSH 的安装提示启用或重启，确认插件管理中的 **会话命名** 行已开启，然后在设置 → **实用工具** → **会话命名** 选择模型。命名模型需支持图片；默认跟随该会话的模型。

使用新命名功能后的消息树会话需要保留配套的 `0.2.16` 兼容实现；若要降级消息树，应先恢复使用前的完整备份。

## 使用限制

- 全会话输入超出预算时保留原名并报告，不会自动截断或分段摘要。
- 与其他接管标题服务或覆盖重命名窗口的插件同时运行时，需检查设置页的冲突提示；接口不匹配时保留原生重命名窗口。
- 升级后需重启 DSH 并刷新浏览器，使 Host 与客户端版本一致。
